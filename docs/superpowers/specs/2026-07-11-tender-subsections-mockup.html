How it works

Pick a view, not a filter combo

The sidebar splits every tender into plain decision stages — To Bid, Worth a Look, Closing Soon, New / Unscored, All. Non-technical users pick where the work is instead of assembling eleven dropdowns. Live counts show where attention is needed.

Refine only when you need to

Each view starts clean: a search box and a Refine button. Power users open Refine for the full filter set (portal, location, worth, eligibility, closing window, match band) — layered within the chosen view, never replacing it. The count badge shows how many refinements are active.

Colour carries meaning

Each view has one semantic colour — emerald = ready to bid, amber = closing soon, blue = new — echoed on the sidebar dot, the header pill, and the card’s match score, so state reads at a glance without reading a word.

Nothing is lost

Every current filter still exists; it just moves into Refine or the view definitions. Deep links work (/tenders/to-bid), so a view is shareable and bookmarkable. “All Tenders” is always one click away for anyone who wants the full list.
